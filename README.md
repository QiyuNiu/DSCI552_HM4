# DSCI 552 Homework 4

This folder contains Qiyu Niu's Homework 4 submission.

## Contents

- `notebook/Niu_Qiyu_HW4.ipynb`: completed and executed homework notebook
- `data/AReM/`: the 88 AReM CSV files and the two data-description PDFs
- `requirements.txt`: Python packages used by the notebook

## Run

Install the dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

Run Jupyter from the notebook folder so the relative data path stays correct:

```bash
cd notebook
jupyter notebook Niu_Qiyu_HW4.ipynb
```
